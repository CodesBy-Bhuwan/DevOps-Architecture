# 🛠️ Ansible

> Configuration-management and automation layer used to configure the local and AWS environments after the infrastructure exists.

## 📦 Requirements

| Tool | Requirement | Purpose |
|---|---|---|
| Ansible | `>= 2.12` | Run playbooks |
| Python | `>= 3.8` | Ansible runtime |
| SSH | Required | Remote server access |

---

## 🌍 Choose an Environment

### AWS

```bash
cd ansible
ansible-playbook -i inventory/aws.ini playbooks/site.yml
```

### Development / Vagrant

```bash
cd ansible
ansible-playbook -i inventory/dev.ini playbooks/site.yml
```

### Production

```bash
cd ansible
ansible-playbook -i inventory/prod.ini playbooks/site.yml
```

> AWS inventory is generated by Terraform. Do not manually edit `inventory/aws.ini`.

---

## ⚙️ Initial Setup

Before running Ansible against AWS:

```bash
ls inventory/aws.ini
```

Make sure the SSH key referenced by the inventory exists and has secure permissions:

```bash
chmod 600 <ssh-key>
```

Test connectivity:

```bash
ansible all -i inventory/aws.ini -m ping
```

## ▶️ Lifecycle Control

Start Jenkins:

```bash
ansible-playbook -i inventory/aws.ini playbooks/control/start/jenkins.yml
```

Stop Jenkins:

```bash
ansible-playbook -i inventory/aws.ini playbooks/control/stop/jenkins.yml
```

Start everything:

```bash
ansible-playbook -i inventory/aws.ini playbooks/control/start/all.yml
```

Stop everything:

```bash
ansible-playbook -i inventory/aws.ini playbooks/control/stop/all.yml
```

Check status:

```bash
ansible-playbook -i inventory/aws.ini playbooks/control/status/all.yml
```

## 🔍 Verification

```bash
ansible all -i inventory/aws.ini -m ping
```

Run a dry check before changes:

```bash
ansible-playbook -i inventory/aws.ini playbooks/site.yml --check
```

Inspect inventory:

```bash
ansible-inventory -i inventory/aws.ini --list
```

## 🧯 Troubleshooting

| Symptom | Likely Cause | Check |
|---|---|---|
| `UNREACHABLE` | SSH/network/security group issue | Verify port 22 and SSH access |
| `Permission denied (publickey)` | Wrong key/permissions | Check SSH key and `chmod 600` |
| `aws.ini` missing | Terraform has not generated it | Run Terraform first |
| `docker: not found` | Docker setup was skipped | Run `playbooks/docker.yml` |
| Tool integration fails | Install succeeded but wiring failed | Re-run the relevant `integrate-*.yml` playbook |
| Container not running | Lifecycle state changed | Use `control/status/all.yml` |
